Gutenberg blocks for small-business sites: business hours with a live "Open now" badge, FAQ, pricing table, testimonials, team member and call to action.

== Description ==

* Business hours with holiday closures, overnight hours and an "Open now" badge that stays correct on cached pages.
* FAQ accordion with FAQPage structured data; LocalBusiness structured data for opening hours.
* Pricing table, testimonials, team member and call-to-action blocks.
* Accessible markup (axe-core checked), and styles and scripts load only on pages that use the blocks.

== Installation ==

1. Upload the plugin folder (with its build folder) and activate it.
2. Add blocks from the "Business" category in the block inserter.
